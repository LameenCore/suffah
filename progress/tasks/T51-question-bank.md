## Why
Checkpoint/assessment/exam questions are generated and buried in JSON. A managed bank lets
admins review, disable weak items, and see which questions discriminate.

## Done when
- [ ] A question bank view per course/unit; enable/disable an item; edit + re-version
- [ ] Item analytics: p-value (difficulty) and discrimination index from real attempts
- [ ] Weak/miskeyed items flagged; grading pulls only enabled items
